# Impeccable — adaptación de diseño para Codex

Esta skill adapta criterios de auditoría y acabado de Impeccable. Incluye una guía de revisión propia; no incluye el ejecutor original, sus agentes auxiliares ni comandos de la CLI de Impeccable. No afirmar que se ejecutó esa CLI al usar esta adaptación.

Leer [coordinación](references/coordination.md) y [revisión de interfaces](references/design-review.md). Identificar si el usuario pide auditoría, refinamiento, rediseño o implementación nueva. Leer el contexto disponible del proyecto y examinar el alcance concreto antes de proponer cambios.

Para auditar, entregar hallazgos con ubicación, evidencia, gravedad y arreglo. Para mejorar, aplicar correcciones autorizadas y probar la interfaz con las herramientas disponibles del proyecto. Conservar identidad y comportamiento al refinar; reemplazar la dirección visual sólo dentro de un rediseño solicitado. Mantener las afirmaciones comerciales verificadas.

Priorizar problemas funcionales y de accesibilidad; después jerarquía, layout, tipografía, color y acabado. Usar capturas reales de los tamaños relevantes y comprobar teclado, foco, enlaces, formularios y reduced-motion. Ejecutar build y checks apropiados al cambio. Si falta una herramienta, declarar qué comprobación quedó pendiente sin simular su resultado.

Agrupar correcciones, confirmar el resultado y ampliar la revisión sólo si aparecen fallos concretos. Resumir cambios, evidencia y límites de verificación.
