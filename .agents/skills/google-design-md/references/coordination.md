# Coordinación del conjunto de diseño

Aplicar este orden: instrucciones del usuario y reglas del proyecto; verdad del producto y accesibilidad; DESIGN.md vigente; recomendaciones de estas skills. Tratar prohibiciones estéticas, diales y presets como criterios contextuales, no como permisos para sustituir la marca.

Secuencia para una landing nueva: Awesome Design MD para escoger referencias; UI UX Pro Max para contrastar decisiones; Google DESIGN.md para fijar tokens; Taste para composición y movimiento; Impeccable para inspección y acabado. Leer sólo las referencias pertinentes. Resolver discrepancias en un único DESIGN.md. No mantener dos fuentes de tokens contradictorias.

Si el proyecto es Tiago Systems / DentFlow, confirmar el contexto comercial vigente. Como punto de partida: Tiago Ortega es la persona; Tiago Systems, la marca personal; DentFlow, el producto para clínicas odontológicas. Una landing captura consultas mediante formulario y el CRM centraliza estado, responsable, próxima acción y fecha. Recepción abre WhatsApp y hace seguimiento, incluso con mensajes prellenados. No prometer automatización total, reemplazo de WhatsApp, pacientes ni ingresos garantizados. No inventar clientes, testimonios, métricas ni trayectoria. Etiquetar demostraciones sintéticas.

Priorizar un contacto principal y un enlace claro al producto. No imponer una arquitectura antigua sobre una instrucción actual. Detectar el stack. Mantener dependencias existentes; añadir sólo las justificadas. Usar CSS o la librería de animación existente para interacciones web; usar Remotion cuando se necesite un video o demo animada exportable. No agregar un reproductor pesado sin beneficio comprobable.

Verificar tipografía y navegación a 360/390, 768 y 1280/1440 px; contraste, foco, teclado, formulario, enlaces, reduced-motion y ausencia de desbordes. Inspeccionar capturas reales; no afirmar que una lectura de código demuestra calidad visual. Ejecutar build y checks apropiados si existe implementación. Corregir una tanda de defectos y confirmar una vez; ampliar sólo por fallos concretos. No publicar ni afirmar que hay una landing creada cuando sólo se instalaron las skills.
